# Темы 1-2: Введение в анализ данных и Типы данных

---

## Добро пожаловать в проект!
Вы — новый аналитик данных в крупной розничной сети **ShopMaster** (вымышленный интернет-магазин). 
Ваш руководитель поставил задачу: **понять, что влияет на выручку магазина, и найти способы увеличить прибыль.**

На протяжении всего курса вы будете работать с реальным (синтетическим) датасетом этого магазина.

---

## 1. Что такое анализ данных?
Анализ данных (Data Analysis) — это процесс сбора, очистки, трансформации и моделирования данных с целью обнаружения полезной информации и поддержки принятия решений.

### Зачем бизнесу аналитика?
| Без аналитики | С аналитикой |
|---|---|
| «Кажется, продажи упали» | «Продажи в категории Electronics упали на 12% в марте из-за отсутствия акций» |
| «Давайте запустим рекламу для всех» | «Запустим рекламу для сегмента "Спящие клиенты" — это 200 человек с высоким LTV» |
| «Не знаем, почему клиенты уходят» | «73% ушедших клиентов не совершали покупок > 60 дней и тратили < 500 руб.» |

## 2. Типы данных
Данные бывают разных типов. Понимание типа данных определяет, какие методы анализа применимы.

### 2.1. Количественные (числовые):
- **Непрерывные:** Цена товара (`price` = 199.99), Возраст (`age` = 34.5)
- **Дискретные:** Количество товаров в заказе (`quantity` = 3), Количество покупок за месяц

### 2.2. Качественные (категориальные):
- **Номинальные** (без порядка): Пол (`gender`), Город (`location`), Категория товара (`category`)
- **Порядковые** (с порядком): Оценка товара (1-5 звёзд), Уровень клиента (Bronze → Silver → Gold)

### 2.3. Временные данные:
- Дата покупки (`date`), Дата регистрации (`signup_date`) — позволяют анализировать тренды.

## 3. Наш датасет: Схема базы данных
В реальной компании данные хранятся в реляционных базах данных. Мы сделали для вас выгрузку.

### Таблица `customers` (Клиенты)
| Колонка | Тип | Описание |
|---|---|---|
| `customer_id` | INT | Уникальный ID клиента |
| `age` | FLOAT | Возраст (количественный, непрерывный) |
| `gender` | TEXT | Пол: M/F (категориальный, номинальный) |
| `location` | TEXT | Город (категориальный, номинальный) |
| `signup_date` | DATE | Дата регистрации (временной) |

### Таблица `products` (Товары)
| Колонка | Тип | Описание |
|---|---|---|
| `product_id` | INT | Уникальный ID товара |
| `category` | TEXT | Категория (категориальный) |
| `price` | FLOAT | Цена (количественный) |

### Таблица `transactions` (Покупки)
| Колонка | Тип | Описание |
|---|---|---|
| `transaction_id` | INT | Уникальный ID транзакции |
| `customer_id` | INT | ID клиента (внешний ключ) |
| `product_id` | INT | ID товара (внешний ключ) |
| `date` | DATE | Дата покупки |
| `quantity` | INT | Количество товаров (дискретный) |
