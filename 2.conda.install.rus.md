# Руководство по установке Conda для машинного обучения (Machine Learning)

## 1. Что такое Conda и зачем она нужна?
Conda — это мощный менеджер пакетов и система управления виртуальными окружениями. В машинном обучении (ML) мы часто используем множество различных библиотек (NumPy, Pandas, Scikit-Learn, TensorFlow, PyTorch), которым могут требоваться разные, иногда конфликтующие, версии зависимостей. 

Conda решает эту проблему:
- Позволяет изолировать проекты друг от друга (создавая виртуальные окружения).
- Устанавливает не только Python-пакеты, но и системные зависимости (например, библиотеки C/C++, нужные для вычислений на видеокартах/GPU).

## 2. Anaconda vs Miniconda
- **Anaconda:** Включает в себя Conda, Python и сразу более 1500 предустановленных пакетов для Data Science. Занимает много места (около 3 ГБ).
- **Miniconda:** Включает только ядро Conda, Python и самые базовые пакеты. Занимает мало места (около 400 МБ). Вы сами устанавливаете только то, что вам нужно.

> [!TIP]
> **Рекомендуется использовать Miniconda**, так как она легковеснее, работает быстрее и позволяет держать систему в чистоте, устанавливая только необходимые для конкретного проекта пакеты.

## 3. Установка Miniconda

### Для Windows
1. Скачайте установщик Miniconda для Windows с [официального сайта](https://docs.anaconda.com/free/miniconda/index.html).
2. Запустите `.exe` файл и следуйте инструкциям на экране.
3. **Важно:** При установке рекомендуют оставить галочку "Add Miniconda3 to my PATH environment variable" **снятой**, и использовать специальную командную строку `Anaconda Prompt` из меню "Пуск" для работы с Conda.

### Для macOS
1. Скачайте установщик для macOS (pkg или bash-скрипт) с [официального сайта](https://docs.anaconda.com/free/miniconda/index.html). Убедитесь, что выбрали правильную версию для вашего процессора (Intel x86_64 или Apple Silicon ARM64 / M1 / M2 / M3).
2. Если скачали `.pkg` — просто запустите его как обычный установщик программ.
3. Если скачали `.sh`: откройте терминал и выполните команду:
   ```bash
   bash Miniconda3-latest-MacOSX-x86_64.sh # или имя файла для ARM64
   ```
4. Следуйте инструкциям, нажимая `Enter` для прокрутки лицензионного соглашения, введите `yes` для согласия с условиями и `yes` для инициализации (conda init).
5. Перезапустите терминал.

### Для Linux
1. Откройте терминал и скачайте установочный скрипт:
   ```bash
   wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
   ```
2. Запустите установку:
   ```bash
   bash Miniconda3-latest-Linux-x86_64.sh
   ```
3. Следуйте инструкциям (согласитесь с лицензией, выберите путь установки, обязательно ответьте `yes` на предложение сделать `conda init`).
4. Перезапустите терминал.

## 4. Базовые команды Conda

После перезапуска терминала (или открытия Anaconda Prompt в Windows) вы должны увидеть `(base)` перед строкой ввода. Это означает, что активно базовое окружение Conda.

Проверьте, что Conda установлена правильно:
```bash
conda --version
```

Обновите Conda до последней версии (рекомендуется после установки):
```bash
conda update conda
```

## 5. Создание окружения для Machine Learning

Давайте создадим ваше первое окружение, в котором будут установлены основные библиотеки для анализа данных и ML (Pandas, NumPy, Matplotlib, Scikit-Learn и Jupyter).

**1. Создание окружения:**
```bash
conda create --name ml_env python=3.10
```
*(где `ml_env` - это имя вашего окружения, а `python=3.10` - версия Python. Вы можете выбрать 3.9, 3.11 и т.д.)*

**2. Активация окружения:**
```bash
conda activate ml_env
```
*(Теперь вы должны увидеть `(ml_env)` в начале строки терминала вместо `(base)`)*

**3. Установка пакетов для ML:**
```bash
conda install numpy pandas matplotlib scikit-learn jupyter
```

**4. Запуск Jupyter Notebook:**
Чтобы начать писать код, запустите Jupyter прямо из этого окружения:
```bash
jupyter notebook
```

## 6. Полезные шпаргалки (Cheatsheet)
- **Посмотреть список всех окружений:** `conda env list`
- **Деактивировать текущее окружение:** `conda deactivate` (вернет вас в окружение `base`)
- **Удалить окружение (если оно больше не нужно):** `conda remove --name ml_env --all`
- **Посмотреть список установленных пакетов в текущем окружении:** `conda list`
- **Найти нужный пакет:** `conda search имя_пакета`
